# KNOWLEDGE

Espace destiné aux connaissances réutilisables de #iC AI.

## Catégories

- Recherche technique
- Recherche marché
- Recherche produit
- Recherche scientifique
- Références
- Retours terrain
- Enseignements des expérimentations

## Règle

Une information importante doit être accompagnée de sa source lorsqu'elle provient d'une recherche externe.

Les hypothèses doivent être distinguées des faits vérifiés.
